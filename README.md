# مشروع أبو مالك – النسخة التأسيسية

واجهة عربية RTL بهوية كحلي وذهبي، مجهزة كواجهة ويب متجاوبة وPWA، مع إعداد أولي لتغليفها كتطبيق Android باستخدام Capacitor.

## ما تم تجهيزه
- واجهة رئيسية احترافية وأقسام الذهب والعملات والحاسبة والمقالات.
- تصميم متجاوب مع شريط تنقل سفلي للموبايل.
- PWA: manifest + service worker + أيقونة.
- إعداد Capacitor لتجهيز Android.
- نقاط ربط منفصلة لخلاصة بلوجر وواجهة أسعار خارجية.
- لا توجد أسعار تجريبية معروضة على أنها حقيقية.

## تشغيل محلي
يفضل تشغيل الملفات عبر خادم محلي، وليس فتح index.html مباشرة:
```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## ربط المقالات ببلوجر
عدّل `config.js`:
```js
BLOGGER_FEED_URL: "https://asearaldhahab.blogspot.com/feeds/posts/default?alt=json&max-results=20"
```
تم ضبط المشروع حاليًا على مدونة `asearaldhahab.blogspot.com` لقراءة أحدث 20 منشورًا، وعرض أول 4 مقالات في الواجهة مع فتح المقال الأصلي على بلوجر للحفاظ على رابطه الحالي. قد تتطلب بعض إعدادات بلوجر أو النطاق معالجة CORS أو استخدام وسيط backend؛ يجب اختبار الخلاصة بعد رفع الموقع على الاستضافة النهائية.

## عقد بيانات الأسعار المطلوب
لا تضع رابطًا في `MARKET_API_URL` إلا بعد الحصول على موافقة مكتوبة تسمح بإعادة النشر التجاري. يجب أن يعيد endpoint JSON بالشكل التالي، مع تاريخ المصدر الحقيقي واسم المصدر. لا تستخدم تاريخ جهاز الزائر أو وقت جلب الصفحة بدل تاريخ الرصد:
```json
{
  "updatedAt": "2026-11-17T15:30:00+02:00",
  "sourceName": "اسم الجهة المرخصة",
  "sourceUrl": "https://example.com/source",
  "gold": {
    "21": {"buy": 0, "sell": 0},
    "24": {"buy": 0, "sell": 0},
    "18": {"buy": 0, "sell": 0},
    "14": {"buy": 0, "sell": 0},
    "coin": {"buy": 0, "sell": 0}
  },
  "currencies": [
    {"name":"الدولار الأمريكي","code":"USD","buy":0,"sell":0,"source":"اسم البنك"}
  ]
}
```
الأصفار أعلاه أمثلة بنيوية فقط وليست أسعارًا. لا تضع API key أو أسرار مزود البيانات داخل JavaScript للواجهة. استخدم backend وسيطًا، وتحقق من شروط إعادة نشر الأسعار تجاريًا، خصوصًا مع AdSense. لا يتم احتساب جنيه الذهب تلقائيًا، ولا يتم توليد دولار صاغة أو أونصة من سعر صرف تقاطعي. إذا لم تصل قيمة موثوقة، تظهر غير متاحة.

## تجهيز Android
يتطلب Node.js وAndroid Studio وبيئة Android SDK:
```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```
بعدها ابنِ APK/AAB من Android Studio. هذه الحزمة تحتوي إعداد Capacitor والواجهة؛ ملف APK النهائي يحتاج بناءً محليًا عبر Android Studio.

## قبل النشر
1. اعتماد مزود أسعار الذهب والعملات والترخيص التجاري.
2. إنشاء backend آمن لتطبيع البيانات وتخزين آخر تحديث ناجح مع timestamp.
3. ضبط رابط بلوجر الفعلي واختبار CORS والخلاصة.
4. إضافة سياسة الخصوصية وشروط الاستخدام وبيانات التواصل.
5. إدخال أكواد AdSense بعد الموافقة، مع الالتزام بسياساته.
6. اختبار PWA عبر HTTPS، واختبار Android على أجهزة فعلية.
7. إضافة صفحات المقالات والتصنيفات والبحث والروابط القانونية، ثم ربط SEO وبيانات Schema.

## ملاحظات مهمة
هذه نسخة تأسيسية قابلة للتشغيل والتطوير، وليست موقعًا منشورًا ولا APK جاهزًا. لا يوجد اتصال حقيقي بمزود أسعار حتى يتم اختيار مزود مرخص وإعداد endpoint الخاص به.


## إضافات هذه الدفعة
- صفحات أولية لسياسة الخصوصية والشروط وإخلاء المسؤولية.
- صفحة بديلة عند انقطاع الاتصال.
- مثال backend adapter لا يعرض أسعارًا مخترعة، ويحافظ على وسم البيانات القديمة عند فشل التحديث.
- ما زال اختيار مزود مرخص وإعداد بيانات الاعتماد مسؤولية مرحلة الربط التالية.


## حالة الربط بعد التحديث
- تم إيقاف مصدر دليلك من الإعدادات إلى حين إثبات السماح بالاستخدام التجاري.
- جدول العملات يضم 18 عملة منشورة ضمن قائمة البنك المركزي المصري؛ لا تظهر أسعار حتى يتم ربط endpoint موثوق ينقل سعر الشراء والبيع وتاريخ النشر.
- أسعار البنك المركزي يومية؛ لا توصف بأنها لحظية. تحديث الصفحة كل خمس دقائق لا يعني أن المصدر نفسه يحدّث كل خمس دقائق.
- حاسبة الذهب تعمل فقط عندما يتوفر سعر بيع صالح للعيار المختار.
- لا توجد أسعار افتراضية أو fallback ثابت عند فشل المصدر.
